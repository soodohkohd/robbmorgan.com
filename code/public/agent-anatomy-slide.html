Agentic development
Anatomy of an AI Agent
Picture a brilliant consultant in a locked room. No memory, no hands. They can only read the notes you slide under the door and write back. Every other part of an agent exists to feed them, equip them, or check their work.
Key takeaways
The AI asks. Software acts.The model can only request an action. Every change to a real system passes a checkpoint you control, so approvals belong there.
Instructions persuade. Code enforces.Playbooks and house rules are followed most of the time. Anything with safety, cost, or compliance stakes needs a hard check in code.
Building one is not shipping one.A demo needs the model, tools, and loop. Production needs all seven parts, and the human interface is the one teams most often leave too late.
PartWhat it isIn the story
InterfaceWho is in the loop
Where people start the work, watch it happen, approve risky steps, and stop it. A chat window, an IDE, Slack, or a scheduled job.
The client you check with before anything irreversible
MCPWhat it can reach
A standard connector for plugging in systems you don't own: the CRM, the data warehouse, the ticketing system. Build once, reuse everywhere.
Your keys and logins to other departments
SkillsWhat it knows how to do
Your company's playbooks, loaded only when a task calls for them. Your standards, your steps, your security policies, so work is secure by design from the start.
A binder of company procedures, handed in when relevant
AgentHow work gets done
The whole arrangement running as a loop. The model picks the next step, the software carries it out or refuses, and the cycle repeats until the job is done.
You and the consultant, passing notes until the report is finished
ToolsWhat it may ask for
The menu of actions on offer: run a query, send an email, read a file. The model can only request items from this list.
Your list of things you are willing to do for them
ModelWhat does the thinking
The AI itself. It reads and writes, and remembers nothing between requests. It can suggest an action but never perform one.
The consultant: brilliant, forgetful, no hands
PlatformWhere it runs
The managed service you buy AI through. Owns access, spending limits, logging, data location, and the bill.
The agency that employs them and sends the invoice
Framework
Plugin
CLI
CLIA ready-made agent you install, such as Claude Code or Copilot CLI. It bundles everything from Interface down to Tools. You still choose the model and the platform.
PluginAn installable bundle for a CLI: skills, commands, MCP connections, and hooks (automatic checks that can block an action). It’s how most frameworks are delivered.
FrameworkA pack of playbooks and house rules, such as HVE, Superpowers, or GSD. It shapes how the agent works but can’t enforce anything. Engineers also use the word for code libraries like LangGraph.
